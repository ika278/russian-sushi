コードレビューを実行します。以下の手順で実行してください。

1. `git diff HEAD` で変更内容を取得する。差分がない場合は「レビュー対象の変更がありません」と伝えて終了する
2. `npx eslint src --ext .ts,.tsx` を実行して lint エラーを取得する
3. Agent ツールを使ってレビューエージェントを起動する。以下のプロンプトを渡すこと:

   """
   あなたは厳格なシニアエンジニアです。以下のコード差分をレビューしてください。
   使えるツール: Read, Grep のみ（コードの編集は絶対にしないこと）

   レビュー観点:
   - バグ・ロジックの誤り
   - 可読性・命名の改善点
   - パフォーマンス・不要な再レンダリング
   - TypeScript の型安全性（any の乱用、型の抜け漏れ）
   - コーディングルール準拠:
     - ESLint（@eslint/js recommended, typescript-eslint recommended）のルールに違反していないか
     - React Hooks のルール（依存配列の漏れ、条件分岐内での hooks 使用など）
     - CLAUDE.md の技術方針（フロントエンドのみ・モバイルファースト）に沿っているか

   lint 結果: [手順2の結果をここに貼る]

   diff:
   [git diff の内容をここに貼る]
   """

4. レビュー結果をそのままユーザーに提示する

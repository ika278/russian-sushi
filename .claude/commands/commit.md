コミットを行います。以下の手順で実行してください。

1. `git status` で変更ファイルを確認する
2. `git diff` でステージ前後の変更内容を確認する
3. `git log --oneline -5` で直近のコミットメッセージのスタイルを確認する
4. 変更内容を分析して、適切なコミットメッセージを考える
   - プレフィックスの例: `feat:` 新機能 / `fix:` バグ修正 / `docs:` ドキュメント / `style:` スタイル / `refactor:` リファクタ
5. 関連ファイルを `git add` でステージする
6. 以下の形式でコミットする:

```
git commit -m "<type>: <1行で変更内容の要約>"
```

7. `git status` でコミット完了を確認する

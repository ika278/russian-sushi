コミットを行います。以下の手順で実行してください。

1. `git branch --show-current` で現在のブランチを確認する
   - `main` ブランチにいる場合は、変更内容から適切なブランチ名を提案し、ユーザーに確認を取ってから `git checkout -b <ブランチ名>` でブランチを作成して切り替える
   - `feature/` または `fix/` ブランチにいる場合はそのまま続行する
2. `git status` で変更ファイルを確認する
3. `git diff` でステージ前後の変更内容を確認する
4. `git log --oneline -5` で直近のコミットメッセージのスタイルを確認する
5. 変更内容を分析して、適切なコミットメッセージを考える
   - プレフィックスの例: `feat:` 新機能 / `fix:` バグ修正 / `docs:` ドキュメント / `style:` スタイル / `refactor:` リファクタ
6. 関連ファイルを `git add` でステージする
7. 以下の形式でコミットする:

```
git commit -m "<type>: <1行で変更内容の要約>"
```

8. `git status` でコミット完了を確認する

feature ブランチの作業を終了し、PR を作成します。以下の手順で実行してください。

1. `git status` で未コミットの変更がないことを確認する（ある場合はユーザーに確認する）
2. 現在のブランチ名を確認し、`feature/` で始まっていない場合は中断する
3. `git push origin <現在のブランチ名>` で最新状態を push する
4. `gh pr create --base main --head <現在のブランチ名> --title "<ブランチ名から推測したタイトル>" --body "## 変更内容\n\n- \n\n## 確認事項\n\n- [ ] 動作確認済み"` で PR を作成する
5. 作成された PR の URL を表示して完了を伝える

# ロシアン寿司

10貫の寿司の中に1つだけワサビ入りが隠れている、罰ゲーム決定ゲームです。
スマホを順番に回しながら1人ずつ寿司を選び、ワサビを引いた人が負けです。

## 遊び方

1. スタートボタンを押してゲームを開始
2. スマホを順番に回して、1人ずつ寿司を1貫タップ
3. **SAFE** が出たら次の人へスマホを渡す
4. **OUT!** が出たらその人の負け！
